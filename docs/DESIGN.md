# Olivia 设计语言

> 关键词：**橄榄 / 量化线 / 纸感 / 生长**。
> 一句话：把橄榄树的枝叶拆成四种粗细的竖线，让它随加载一格格长出来，长成后收进界面里。

参考来源：StyleKit *Quantized Line Field*（亮度 → 四档竖线 / 缓慢漂移 / 弹簧位移 / 网格对齐扫描框），Axolotl Launcher（左栏导航 + 主区卡片 + 顶部实例栏的启动器骨架）。两者都只借**结构**，配色、动效节奏、图形全部重做。

---

## 1. 设计令牌

### 1.1 颜色

| 语义 | 值 | 用途 |
|---|---|---|
| `--paper` | `#F4F1E6` | 画布底色，一张微暖的纸 |
| `--panel` | `#FBFAF3` | 卡片 / 面板 |
| `--panel-2` | `#EFEBDB` | 次级填充、轨道、缩略图底 |
| `--ink` | `#23261C` | 主文字（近黑带绿） |
| `--ink-2` | `#5E6350` | 正文次级 |
| `--muted` | `#8A8F7A` | 注释、时间戳 |
| `--line` | `#DBD5C2` | 1px 分隔线 / 卡片描边 |
| `--olive` | `#5C6B39` | 品牌主色（叶） |
| `--olive-deep` | `#39441F` | 主按钮、深色块（干） |
| `--leaf` | `#A9B292` | 银绿叶、图表辅助 |
| `--gold` | `#C09A46` | 果实、赞助、强调数值 |
| `--danger` | `#A9482F` | 崩溃 / OOM / 未配置 |
| `--info` | `#3D6B84` | 中性信息、链接 |

**禁用**：紫蓝渐变、玻璃拟态、大面积模糊阴影、`backdrop-filter`、渐变文字。
"体积感"只用**错位底板**（同尺寸、下移 6px、1px 描边、0.7 透明度）实现，hover 时底板再下移，位移 300ms ease-out。

对比度：正文 `--ink` 于 `--paper` 为 12.8:1；`--muted` 于 `--paper` 为 3.9:1，仅用于 12px 以上非关键文本。所有正文 ≥ 4.5:1。

### 1.2 字体

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 显示 | `Georgia, "Songti SC", "Noto Serif SC", serif` | 页面主标题、启动页 OLIVIA 字标 |
| 界面 | `"Segoe UI", "Microsoft YaHei", system-ui, sans-serif` | 正文、按钮、表单 |
| 数据 | `"Cascadia Mono", Consolas, monospace` | 显存、温度、PID、路径、坐标 |

字号：主标题 28–32px / 卡片标题 15px / 正文 13–13.5px / 注释 12px。
数字统一 `font-variant-numeric: tabular-nums`，避免逐帧跳动。

### 1.3 形状

- 卡片圆角 `14px`，按钮 `9px`，标签 `6px`，缩略图 `10px`
- 卡片内边距 16–18px，卡片间距 14px，页面左右留白 26px
- 描边一律 1px `--line`；**不用阴影**
- 视觉分隔优先用四档线宽，而非渐变

### 1.4 四档线宽（品牌基因）

```
0.38  最细：网格、次要刻度、分隔
1.12  常规：正文描线、图表基线
2.28  强调：进度、选中态、数据曲线
3.80  最重：图形主体、当前项
```

所有自绘图形（启动树、迷你图、缩略图占位、空状态插画）**只允许这四档**，不允许连续线宽。这是与参考风格保持同源的关键。

## 2. 启动动画

### 2.1 构图

- 全屏纸色底 `#F4F1E6`，中央画布 `min(56vh, 560px)` 见方
- 橄榄树：树干 + 3 级分叉 + 团簇状叶冠，**由竖线场重建**，不是位图也不是 SVG
- 左上：`OLIVIA`（衬线）/ `ComfyUI 启动器`（无衬线小字）/ `v0.1.0-m1`（等宽）
- 左下：当前加载说明 + 百分比；右下：`跳过启动动画`
- 底部：240px 进度轨道，上有 4 个刻度点（呼应四档线宽）

### 2.2 量化线场算法

| 参数 | 值 |
|---|---|
| 采样画布 | 720×720 离屏，黑底白树 |
| 网格 | 96×96（每格 7.5px，即 7×7 超采样） |
| 显示 | 96 列 × 48 段（每段 = 相邻两行亮度均值） |
| 量化阈值 | 0.12 / 0.42 / 0.89 |
| 线宽 | 0.38 / 1.12 / 2.28 / 3.80（× cellSize / 5.25） |
| 透明度 | 0.20 / 0.55 / 0.82 / 1.0 |
| 像素读取 | **全程只读一次**，resize 不重采样 |

**漂移噪声**：128×128 种子格（xorshift，seed 7319），平滑双线性值噪声。每段取
`x = c * 0.15 + 3`，`y = r * 0.16 - t * 0.17`，整体缓慢向下漂；合成
`L' = L * 0.94 + noise * 0.12 * (0.25 + L * 0.75)`。

**指针响应**：指针进入或移动超过 1.5px 时 `pulse = 1`；影响半径 = 画布宽 × 0.25；
`influence = max(0, 1 - d/r)²`，径向位移 × 25（纵向 × 0.58）。用阻尼弹簧回位
（k = 145，c = 19，积分步长 ≤ 1/30 s），脉冲按 `exp(-dt * 5.5)` 衰减。
**静止的指针不能把线永久撑开**——鼠标离开后必须回到网格原位。

**生长**：`frontier = easeOutCubic(progress) × (ROWS + 2)`，只绘制 `r < frontier` 的段，前沿处 1 段内做透明度软边。`progress` 由**真实初始化任务**驱动（解析环境 → 校验 CUDA → 载入实例 → 连接本地服务），不是计时器。

**果实**：`progress > 0.72` 后，叶冠按固定种子点亮 7 个金色小圆点（半径 2.5px），刷新不变。

### 2.3 过渡（不许硬切）

1. `progress = 1` → 前沿冲顶，停留 420ms（让人看见完整的树）
2. splash `opacity 1→0` + `scale 1→1.02`，900ms `cubic-bezier(.2,.7,.2,1)`
3. 主界面同时 `opacity 0→1`、`translateY 8px→0`，同曲线 900ms
4. 两者交叉 900ms，无空白帧；结束后停止 rAF 并释放离屏画布
5. 点"跳过"走同一条过渡，只是把 progress 直接推到 1

`prefers-reduced-motion: reduce`：不跑 rAF，直接绘制 progress = 1 的静态帧，300ms 淡入主界面。

### 2.4 性能约束

- 4608 段/帧，按四档线宽**分组为 4 条 Path**，每帧只 stroke 4 次
- DPR 变化时先更新 backing store 再重绘；`ResizeObserver` 不触发重采样
- 页面隐藏（`visibilitychange`）、离屏（`IntersectionObserver`）暂停 rAF
- 暂停恢复时重置时间戳，避免一次巨大 dt

## 3. 主界面

### 3.1 骨架

```
┌──────────┬────────────────────────────────────────────┐
│ 品牌      │ 顶部栏：实例选择 ▾ ｜ 状态 ｜ 端口 ｜ 启动    │
│          ├────────────────────────────────────────────┤
│ 总览      │                                            │
│ 实例      │   页面内容（卡片网格）                       │
│ 队列      │                                            │
│ 硬件      │                                            │
│ 资产      │                                            │
│ 模型      │                                            │
│          │                                            │
│ ─────    │                                            │
│ 赞助/版本 │                                            │
└──────────┴────────────────────────────────────────────┘
```

- 左栏 236px，纸色加深一档，1px 右边线；导航项 38px 高、9px 圆角、选中态为面板色 + 描边（不用色块填充）
- 顶栏 64px：实例下拉（带版本与 CUDA 角标）、运行状态点、端口、主按钮「启动 / 停止」
- 内容区 12 列栅格，卡片按需跨列

### 3.2 页面职责

| 页面 | 必须回答的问题 |
|---|---|
| **总览** | 我现在能不能出图？还差什么？ |
| **实例** | 我装了哪些 ComfyUI？占用多少？怎么再加一个？ |
| **队列** | 什么在跑？跑到哪个节点？还要多久？ |
| **硬件** | GPU 现在多热多忙？**是哪条工作流在吃显存？** |
| **资产** | 产物在哪？没指定怎么指定？ |
| **模型** | 缺什么权重？放哪？ |
| **设置** | 镜像、并发、采样频率、赞助位开关 |

### 3.3 状态与空态

- **未指定资产目录**：总览顶部常驻警示条 + 资产页整页空态。文案明确后果，主按钮 `选择文件夹`
- **从未部署**：总览直接变成部署向导第一步，不给一堆空卡片
- **实例运行中**：顶栏状态点变绿并呼吸（2s，只改 opacity），按钮变「停止」
- **GPU 不可用**：硬件页显示原因（无 NVIDIA 驱动 / WSL / 非 N 卡），仍显示内存与磁盘
- **OOM**：错误卡片给出「降分辨率 / 换 fp8 / 开 --lowvram」三个按钮，而不是只报错

### 3.4 画布嵌入的视觉统一

画布通过 iframe 加载 `/comfy/`，必须做到：

- 注入主题变量，把 ComfyUI 的深色背景、节点色、连线色映射到橄榄纸感（浅色为默认，深色作为可选主题）
- 隐藏 ComfyUI 自带顶栏与侧栏，由启动器顶栏统一承载
- 画布外框与启动器面板共用 14px 圆角与 1px 描边，**看起来是同一张界面**
- 加载期间显示启动器自己的骨架屏，禁止出现 ComfyUI 原生 splash

## 4. 交互细节

- 所有可点元素 300ms ease-out 位移，不做弹性回弹（禁 bounce / elastic）
- 进度数值每 500ms 更新一次，tabular-nums，不逐帧抖动
- 危险操作（删除实例）二次确认并显示占用空间
- 键盘：`1–7` 切换页面，`Esc` 关弹窗，`Ctrl+Enter` 启动/停止
- 焦点可见：2px `--info` 描边 + 4px offset，绝不 `outline: none`
- 文案：中文为主，术语保留英文（CUDA / VRAM / KSampler），数字与单位间加空格

## 5. 赞助位规范

按需求：**首页一个 + 侧栏一个**。

| 位置 | 形态 | 约束 |
|---|---|---|
| 总览页底部 | 一张与功能卡片同尺寸的卡，`--panel-2` 底，金色果实图标 | 不遮挡任何操作，不与"未指定资产目录"警示条同屏优先 |
| 侧栏底部 | 一行文字链 + 爱发电图标，高 38px | 与版本号同行，不占独立区块 |

- 设置中提供「隐藏赞助位」开关，默认**显示**
- 赞助位不得使用弹窗、不得自动轮播、不得诱导点击
- 爱发电入口固定指向项目主页，不做任何付费墙
