# Olivia 设计语言

> 关键词：**量化线 / 界面让位 / 数据先行**。
> 一句话：界面是暗色的、安静的、让作品突出的；四档线宽是唯一的装饰语言；颜色只用于传达状态与数据，不用于讲故事。

> **配色原则（v2 修订）**：Olivia 源自橄榄树，但**产品配色不取自橄榄绿**。字面联想（绿=橄榄）是最低级的一种命名映射，且橄榄绿作为工具主色有三个实际问题：与"成功/正常"状态色混淆、与大量 AI 工具的同质化、以及无法解释为什么"橄榄树"该是绿色而不是果实金或树干棕。配色服务于两件事：**让生成的图像作品突出**、**让硬件数据可读**。橄榄树只保留在启动动画的图形结构里，不进入界面配色。

参考来源：StyleKit *Quantized Line Field*（亮度 → 四档竖线 / 缓慢漂移 / 弹簧位移 / 网格对齐扫描框），Axolotl Launcher（左栏导航 + 主区卡片的启动器骨架）。两者都只借**结构**。

## 1. 配色方案

产品内置四套主题，用户可在设置中切换，默认 **石墨靛**。所有主题必须满足第 1.3 节的对比度要求。

### 1.1 四套主题

| 主题 | 定位 | 背景 | Accent | 适合 |
|---|---|---|---|---|
| **石墨靛**（默认） | 暗色 · 通用 | `#0B0C10 → #13151B → #1B1E27` | 靛蓝 `#7C8CFF` | 绝大多数用户；与 ComfyUI 官方深色画布衔接最自然 |
| **暗房琥珀** | 暖暗 · 创作感 | `#121110 → #1A1815 → #241F1A` | 琥珀 `#E8A33D` | 长时间看图；暗房隐喻贴合图像生成 |
| **瓷白朱砂** | 亮色 · 编辑感 | `#F7F7F5 → #FFFFFF → #EFEFEC` | 朱砂 `#D93A2B` | 白天办公环境；打印截图 |
| **深青仪表** | 冷暗 · 硬件感 | `#0A1416 → #102024 → #163036` | 青 `#35C4D7` | 强调硬件监控属性的用户 |

### 1.2 语义色（所有主题共用结构，值随主题）

| 语义 | 用途 |
|---|---|
| `--bg0 / --bg1 / --bg2` | 页面底 / 卡片 / 二级填充，三级亮度差 ≥ 4% |
| `--line` | 1px 描边与分隔线 |
| `--ink / --ink2 / --muted` | 主文字 / 次级 / 注释 |
| `--accent / --accent2` | 主操作、选中态、图表主曲线；accent2 为 hover/按下 |
| `--ok / --warn / --danger` | 成功 / 警告 / 错误，**只用于状态，不做装饰** |
| `--info` | 中性信息、图表副曲线、CUDA 角标 |
| `--on-accent` | accent 底上的文字色（暗 accent 配亮字，反之亦然） |

### 1.3 对比度硬约束

- 正文（`--ink` 于 `--bg1`）≥ 7:1
- 次级文字（`--ink2` 于 `--bg1`）≥ 4.5:1
- 注释（`--muted`）≥ 3:1，且仅用于 ≥ 11px 非关键文本
- `--accent` 于 `--bg0` ≥ 3:1（用于图形/描边），accent 上的文字用 `--on-accent` ≥ 4.5:1
- `--ok / --warn / --danger` 于 `--bg1` ≥ 3:1
- `--on-accent` 于 `--accent2` ≥ 4.5:1（主按钮常态底就是 accent2，hover 不换底）
- `::selection` 的文字色用 `--bg1`（于 accent ≥ 4.5:1）

任何新主题必须在 PR 里附对比度计算结果，不达标不合并。该检查由 `scripts/ci/check_contrast.py` 在 CI 自动执行，直接读原型的 THEMES 表算 WCAG 比值。

### 1.4 用色纪律

- **界面是舞台，作品是主角**：大面积只用中性三级灰，色彩只出现在交互元素、状态点、数据曲线上
- 状态色不挪用：绿色只表示"正常/运行中"，红色只表示"错误/OOM/未配置"，绝不用于选中态或品牌强调
- 不使用渐变按钮、玻璃拟态、大面积模糊阴影
- 图表最多两条曲线：accent（主）+ info（副），需要第三条时先质疑要不要
- 主按钮 hover 只提亮描边并上移位移，**不换底色**——on-accent 文字落在变亮的 accent 上会跌破 4.5:1
- 暗色主题下禁用纯黑 `#000` 与纯白 `#fff` 作大面积底/字（`--bg0` 接近但不等于黑）

### 1.5 v2.1 修订（2026-11-03）

四主题经对比度实测后微调四处，其余令牌不动：

| 主题 | 令牌 | 旧值 → 新值 | 原因 |
|---|---|---|---|
| 暗房琥珀 | `--warn` | `#E8A33D` → `#E8C063` | 与 `--accent` 同值，启动树果实画在同色枝线上不可见，警告态也长得像品牌强调；偏柠黄后与 accent 拉开 1.5:1 明度差 |
| 深青仪表 | `--info` | `#7FD4E8` → `#A9E4EF` | 与 `--accent` 明度几乎相同（1.24:1）且同色相，是该主题双曲线图最难读的原因；提亮后达 1.50:1，对齐石墨靛的信息层级（1.64:1） |
| 全部 | 主按钮 hover | 换 accent 底 → 只提亮描边 + 位移 | 石墨靛白字落在 hover 的 accent 上仅 2.98:1，违反 §1.3；hover 语义改由描边与上移承担 |
| 全部 | `::selection` 文字 | `--bg0` → `--bg1` | 瓷白朱砂下 bg0 于 accent 仅 4.33:1；bg1 全主题 ≥ 4.65:1 |

## 2. 设计令牌

### 2.1 字体

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 显示 | `Georgia, "Songti SC", "Noto Serif SC", "Source Han Serif SC", SimSun, serif` | 页面主标题、启动页 OLIVIA 字标；SimSun 兜底 Windows（Songti SC 仅存在于 macOS） |
| 界面 | `"Segoe UI", "Microsoft YaHei", system-ui, sans-serif` | 正文、按钮、表单 |
| 数据 | `"Cascadia Mono", Consolas, monospace` | 显存、温度、PID、路径、坐标 |

字号：主标题 28–32px / 卡片标题 15px / 正文 13–13.5px / 注释 12px。
数字统一 `font-variant-numeric: tabular-nums`，避免逐帧跳动。

### 2.2 形状

- 卡片圆角 `14px`，按钮 `9px`，标签 `6px`，缩略图 `10px`
- 卡片内边距 16–18px，卡片间距 14px，页面左右留白 26px
- 描边一律 1px `--line`；不用阴影
- "体积感"只用**错位底板**（同尺寸、下移 6px、1px 描边、0.75 透明度）实现，hover 时底板再下移，位移 300ms ease-out

### 2.3 四档线宽（品牌基因）

```
0.38  最细：网格、次要刻度、分隔
1.12  常规：正文描线、图表基线
2.28  强调：进度、选中态、数据曲线
3.80  最重：图形主体、当前项
```

所有自绘图形（启动树、迷你图、缩略图占位、空状态插画）**只允许这四档**，不允许连续线宽。

## 3. 启动动画

### 3.1 构图

- 全屏 `--bg0` 底，中央画布 `min(56vh, 560px)` 见方
- 橄榄树：树干 + 主枝 + 递归分枝 + 分瓣叶冠，**由竖线场重建**，不是位图也不是 SVG
- 树形轮廓：上半饱满、底部内收、冠底开天窗露出主枝分叉；枝条角度钳制在上半平面，不出现下垂裸枝
- 线条颜色用 `--accent`，果实用 `--warn`（跟随主题）
- 左上：`OLIVIA`（衬线）/ `ComfyUI 启动器` / `v0.1.0-m1`（等宽）
- 左下：加载说明 + 百分比 + 240px 进度轨道（4 个刻度点）；右下：`跳过启动动画`

### 3.2 量化线场算法

| 参数 | 值 |
|---|---|
| 采样画布 | 720×720 离屏，黑底白树 |
| 网格 | 96×96（每格 7.5px，7×7 超采样） |
| 显示 | 96 列 × 48 段（每段 = 相邻两行亮度均值） |
| 量化阈值 | 0.12 / 0.42 / 0.89 |
| 线宽 | 0.38 / 1.12 / 2.28 / 3.80（× cellSize / 5.25） |
| 透明度 | 0.20 / 0.55 / 0.82 / 1.0 |
| 像素读取 | **全程只读一次**，resize 不重采样 |
| 背景处理 | L < 0.12 的段直接跳过，避免出现画布矩形底 |

**漂移噪声**：128×128 种子格（xorshift，seed 7319），双线性值噪声，`x = c*0.15+3, y = r*0.16 - t*0.17`，合成 `L' = L*0.94 + n*0.12*(0.25 + L*0.75)`。

**指针响应**：移动超过 1.5px 触发 `pulse=1`；影响半径 = 画布 × 0.25；`influence = max(0,1-d/r)²`，位移 ×25（纵向 ×0.58）；阻尼弹簧回位（k=145, c=19，步长 ≤ 1/30s），脉冲 `exp(-dt*5.5)` 衰减。**静止指针不能把线永久撑开**。

**生长**：`frontier = easeOutCubic(progress) × (SEG+2)`，progress 由真实初始化任务驱动。

**果实**：progress > 0.72 后按固定种子点亮 7 个 `--warn` 色小圆点。

### 3.3 过渡

1. progress = 1 → 停留 420ms
2. splash `opacity 1→0 + scale 1→1.02`，900ms `cubic-bezier(.2,.7,.2,1)`
3. 主界面同时 `opacity 0→1、translateY 8px→0`，同曲线
4. 结束后停止 rAF、释放离屏画布
5. "跳过"走同一条过渡

`prefers-reduced-motion: reduce`：不跑 rAF，直接绘制 progress=1 静态帧，300ms 淡入主界面。

### 3.4 性能约束

- 4608 段按四档分组为 4 条 Path2D，每帧 stroke 4 次
- DPR 变化先更新 backing store；页面隐藏/离屏暂停 rAF；恢复时重置时间戳

## 4. 主界面

### 4.1 骨架

```
┌──────────┬────────────────────────────────────────────┐
│ 品牌      │ 顶部栏：实例选择 ▾ ｜ 主题切换 ｜ 端口 ｜ 启动 │
│          ├────────────────────────────────────────────┤
│ 总览      │                                            │
│ 实例      │   页面内容（卡片网格）                       │
│ 队列      │                                            │
│ 硬件      │                                            │
│ 资产      │                                            │
│ 模型      │                                            │
│          │                                            │
│ ─────    │                                            │
│ 赞助/版本 │                                            │
└──────────┴────────────────────────────────────────────┘
```

- 左栏 236px（`--bg1`），1px 右边线；导航项 38px 高、9px 圆角，选中态 `--bg2` + 描边
- 顶栏 64px：实例下拉（版本 + CUDA 角标）、运行状态点、主题切换器、端口、主按钮
- 内容区 12 列栅格

### 4.2 页面职责

| 页面 | 必须回答的问题 |
|---|---|
| **总览** | 我现在能不能出图？还差什么？ |
| **实例** | 我装了哪些 ComfyUI？占用多少？怎么再加一个？ |
| **队列** | 什么在跑？跑到哪个节点？还要多久？ |
| **硬件** | GPU 现在多热多忙？**是哪条工作流在吃显存？** |
| **资产** | 产物在哪？没指定怎么指定？ |
| **模型** | 缺什么权重？放哪？ |
| **设置** | 主题、镜像、并发、采样频率、赞助位开关 |

### 4.3 状态与空态

- **未指定资产目录**：总览常驻警示条（danger 描边）+ 资产页整页空态 + 主按钮"选择文件夹"
- **从未部署**：总览直接变成部署向导第一步
- **实例运行中**：状态点变 `--ok` 并呼吸（2s，只改 opacity），按钮变「停止」
- **GPU 不可用**：硬件页显示原因，仍显示内存与磁盘
- **OOM**：错误卡片给出「降分辨率 / 换 fp8 / 开 --lowvram」三个按钮

### 4.4 画布嵌入的视觉统一

画布通过 iframe 加载 `/comfy/`，注入主题变量使 ComfyUI 的配色与当前主题一致；隐藏其原生顶栏侧栏；外框共用 14px 圆角与 1px 描边；加载期显示启动器自己的骨架屏。注入脚本必须做特性检测，失效时降级为原生外观，绝不白屏。

## 5. 交互细节

- 所有可点元素 300ms ease-out 位移，禁弹性回弹
- 进度数值每 500ms 更新，tabular-nums
- 危险操作二次确认并显示占用空间
- 键盘：`1–7` 切页面，`Esc` 关弹窗，`Ctrl+Enter` 启动/停止
- 焦点可见：2px `--accent` 描边 + 3px offset
- 文案：中文为主，术语保留英文（CUDA / VRAM / KSampler），数字与单位间加空格
- 主题切换即时生效（CSS 变量 + canvas 重绘），选择持久化到 `localStorage`（key：`olivia.theme`）

## 6. 赞助位规范

| 位置 | 形态 | 约束 |
|---|---|---|
| 总览页底部 | 一张与功能卡片同尺寸的卡，`--bg1` 底，`--warn` 果实图标 | 不遮挡操作 |
| 侧栏底部 | 一行文字链 + `--warn` 圆点，高 38px | 与版本号区块分离 |

- 设置中提供「隐藏赞助位」开关，默认显示
- 不用弹窗、不轮播、不诱导点击；不做付费墙
