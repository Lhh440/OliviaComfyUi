## 1. 自研节点编辑器（M2.1–M2.3）

### 1.1 范围纪律：名单来自 M1 的真实数据

「覆盖高频 20% 节点」不是拍的：M1.2 起队列页记录每次执行用到的节点名，按真实出现频次截断，预计 30 个左右（CheckpointLoader / CLIPTextEncode / KSampler / VAEDecode / SaveImage / LoraLoader / EmptyLatentImage 等）。名单固化成 `packages/editor/nodes.json`，每条带输入/输出/参数 schema。

**灰盒是硬底线**：名单外的节点在自研画布上渲染为灰盒——显示标题与已连线端口，参数不可改，提示「去嵌入画布编辑」。灰盒保证**任何官方工作流都不会因为编辑器不认识而打不开**，这是双模式并存能成立的前提。

### 1.2 工作流格式：只读写官方 UI 格式

ComfyUI 工作流 JSON 有 UI format（带 nodes/links/groups 位置信息）与 API format（执行图）两种。自研编辑器只处理 UI format：

- 读：完整解析；未知节点 → 灰盒，原样保留其全部字段
- 写：只允许改动已知节点的参数与连线；灰盒节点**原样写回，不做有损转换**
- API format 在提交执行时由启动器从 UI format 推导

代价：schema 跟随上游演进。对策：CI 用一组官方示例工作流做解析快照测试，每次 ComfyUI 大版本回归。

### 1.3 渲染层：M2.1 开工前必须先出 ADR-0010

候选：Canvas 2D（延续量化线语言，四档线宽天然适用）/ SVG / DOM。倾向 Canvas 2D + 独立命中测试层，但**此条不写透不动工**——编辑器在 ADR-0010 合并前不出现一行渲染代码。

### 1.4 里程碑

| 版本 | 内容 | 验收 |
|---|---|---|
| M2.1 | 图数据模型 + 官方 UI 格式读写 + 灰盒渲染 | 官方示例工作流 100% 可打开，未知节点字段零丢失 |
| M2.2 | 已知节点参数编辑 + 连线 + 撤销栈 | 断网、无 ComfyUI 实例时也能编辑并保存 |
| M2.3 | 双模式并存：新建默认自研，一键切换嵌入画布 | 自研 ↔ 嵌入互相拷贝工作流不丢数据 |

## 2. 模型市场（M2.4）

定位先说死：**只做索引、下载、校验、归位。不自建托管，不做评分社区，不做任何分发。**

- 数据源：HF 镜像 / ModelScope / Civitai 的**公开元数据**，缓存进本地 sqlite
- 下载：Range 断点续传 + sha256 校验 + 磁盘空间预检（空间不足在下载**前**拦截，不在下载到 90% 时失败）
- 归位：按 `models/*` 目录结构落盘，可选写入 `extra_model_paths.yaml` 共享区
- 合规：每条目标注许可证字段；Civitai 只索引元数据，下载始终指向上游原始地址

| 版本 | 验收 |
|---|---|
| M2.4 | 断点续传可用；sha256 不匹配即拒绝落盘并清理临时文件 |

## 3. 兼容矩阵推荐（M2.5）

M1 的 `compat.json` 是内置静态表；M2 升级为**社区可贡献的数据集**：

- 独立成 `compat/` 目录 + JSON Schema 校验，PR 即贡献
- 每条推荐强制标注来源：`实测` / `推断` / `社区报告`，UI 显示口径——延续 ADR-0007 的「不骗用户」
- CI 每日跑主流组合冒烟（uv 装 torch → import → 最小推理），通过的组合自动打「实测」标记

## 5. 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 编辑器范围失控（重走 ComfyUI 十万行） | 项目烂尾 | 灰盒 + 双模式是硬底线，名单外节点禁止实现参数面板 |
| 上游 workflow schema 变更 | 解析失效 | 快照测试 + 灰盒兜底，绝不白屏 |
| 模型版权争议 | 项目声誉 | 只索引不托管，分发留在上游 |
| 兼容数据被污染（错误推荐烧用户的卡） | 信任崩塌 | 来源标注 + CI 实测门槛 |
